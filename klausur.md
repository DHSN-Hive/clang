# Klausur

Klausur besteht aus:
3 Blöcken

Block A
Theorie oder Praxis
1 von 2 Aufgaben vollständog lösen

Block B
3/4 Der aufgaben lösen
Grundlagen

Block C
Aufgabe muss gelößt werden
Analyse eines Programmes (meist C++)
Compilerausgaben des gdb's
Problem identifizieren & lösen

# Debugger
Für Klausur werden nur 8 Befehle benötigt
-g für Debuggin Informationen werden in bin. hinein 

## gdb

list <zeilennummer> => codeausgabe
break <zeilennummer> => breakpoint für zeile (bleibt vor ausführen der Zeile stehen)
pun 
info locals => untersuchen aller lokalen variablen

cc --ansi -g -o
